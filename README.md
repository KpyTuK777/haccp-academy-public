# HACCP Academy — публічна версія

Навчальні модулі, тести, довідник, іспит та прогрес на пристрої.
Оригінальні фотографії виключені з цього репозиторію та його історії. Посилання на сторінки — звичайний текст. Приватний репозиторій з оригіналами не змінювався.

Перевірка: node test.cjs. Публікація: GitHub Pages, main, коренева папка.

Встановлення: iPhone — Safari → Поділитися → На початковий екран. Android — Chrome → меню → Установити / Додати на головний екран. Потрібне з’єднання з інтернетом. Прогрес між пристроями автоматично не синхронізується; доступні експорт та імпорт.

Додано напрям «Гігієна персоналу»: 25 сторінок, 7 модулів, 60 запитань із чотирма відповідями. Перемикання — на «Моєму просторі» або в меню. Кожен напрям має окремий прогрес, іспит, помилки та резервну копію. Попередній прогрес першого напряму збережено.
